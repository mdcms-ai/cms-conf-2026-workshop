An agent rewriting 500 posts should go through the same validation,
permissions and version history as an editor publishing a single page.

## Three things an agent needs

- A schema it can read, so it knows what valid content looks like.
- Errors it can act on, so it can correct itself.
- Drafts, so a person decides what goes live.
